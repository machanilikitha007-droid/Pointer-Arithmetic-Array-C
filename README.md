# Pointer Arithmetic on an Array in C

**Author:** M.Likitha

## Description

This program demonstrates pointer arithmetic in C by accessing array elements using a pointer.

## Concepts Used

- Arrays
- Pointers
- Pointer arithmetic
- Dereferencing

## How It Works

The pointer stores the address of the first array element.

`*(ptr + i)` is used to access each array element.
